# 🚀 CampusPulse AI

### AI-Powered College Complaint Management System

CampusPulse AI is a smart web-based complaint management system designed to help students submit campus-related complaints easily. It uses Gemini AI to analyse complaints and automatically categorise them for college administration.

## 🌐 Live Website

[Visit CampusPulse AI](https://famous-manatee-3885fb.netlify.app)

## ✨ Features

- Student complaint submission form
- AI-powered complaint analysis
- Automatic complaint categorisation
- Priority identification (High, Medium, Low)
- Department assignment
- Google Sheets complaint storage
- Responsive website design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- n8n Automation
- Google Gemini AI
- Google Sheets
- Netlify

## ⚙️ Workflow

Student → Website → n8n → Gemini AI → Google Sheets

## 📂 Project Files

- `index.html` – Website structure
- `style.css` – Website design
- `script.js` – Form handling and webhook integration

## 🎯 Project Objective

To simplify college complaint management through automation and artificial intelligence.
